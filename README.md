Telegram Bot on aiogram 3.x

Простой Telegram‑бот на Python с использованием библиотеки aiogram (версия 3+). Реализована базовая обработка команд /start и /help, асинхронная работа через asyncio и поллинг обновлений.

Проект подходит как стартовый шаблон для создания собственных ботов и демонстрации навыков работы с Telegram Bot API, асинхронным кодом и структурой Python‑проекта.

## Особенности
aiogram 3.x (асинхронный подход)
обработка команд через фильтры CommandStart и Command
чистая структура кода без лишних зависимостей
## Как запустить
Клонируйте репозиторий.
Создайте виртуальное окружение и активируйте его.
Установите зависимости: pip install -r requirements.txt.
Создайте файл .env и добавьте BOT_TOKEN=ваш_токен.
Запустите: python bot.py.
## Что можно доработать
добавить кнопки (ReplyKeyboard / InlineKeyboard)
подключить базу данных для хранения пользователей
реализовать машину состояний (FSM) для диалогов
вынести логику в отдельные модули
